## 🚀 Как использовать

1. Скопируйте ссылку на нужный `.m3u` файл:
   `https://raw.githubusercontent.com/gvineon550-coder/autoua/main/zerkalo.m3u`
2. Вставьте в IPTV-плеер (VLC, Kodi, TiviMate, OTT Navigator и др.).

## ⚙️ Как это работает

- `detect_headers.py` — проверяет живость URL, чистит мёртвые, подбирает заголовки.
- `add_user_agent.py` — вставляет `#EXTVLCOPT` в плейлисты.
- GitHub Actions запускается при пуше, по расписанию (пн 04:00 UTC) и вручную.

## 🛠 Ручной запуск

Actions → **Auto-update playlists** → **Run workflow**.
